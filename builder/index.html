What is AgentForge?

AgentForge turns a reviewed App Blueprint into a local-first FastAPI + React product shell with deterministic providers, scoring, optional agent runtime, workspace UI, tests, and CLI validation.

Path 1 Start from an app idea Describe the product, draft a Blueprint, review modules, then run plan/generate. Path 2 Start from an existing repo Run the v0.7 analysis-only Repo Analyzer, paste JSON output, and turn findings into a reviewed Blueprint.
